# Content And Licensing

This repository should contain only content that is safe to share publicly or privately on GitHub.

## Allowed In Repo

- Original project documentation.
- Original schemas and code.
- Original prompt templates.
- Config examples without secrets.
- Demo-safe sample campaign content created for this project.
- Small placeholder files.

## Not Allowed In Repo

- Paid adventure text.
- Rulebook copies or extracted PDF text.
- Private campaign notes.
- Real campaign databases.
- Private player information.
- Generated images/videos intended for private games.
- Downloaded AI models or checkpoints.
- Secrets, API keys, or credentials.

## Sample Content Standard

Sample content should be:

- Original.
- Generic.
- Demo-safe.
- Free of proprietary setting names, adventure text, stat blocks, and copied lore.
- Clearly marked as sample content.

## Imports

Future import tooling should assume imported material is private by default. Imported files should stay outside the repo unless the user explicitly creates sanitized demo samples.
