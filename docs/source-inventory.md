## Startup and side-effect review

- `start-session.bat` delegates to the portable full-profile launcher, preserving the configured/default database. Optional Node children are explicit; no external models/tools start. Tests always override data paths and own their children. Five historical helpers were retired after caller review; see docs/script-retirement.md.
- The executable game-server entrypoint explicitly opens SQLite; importing db.ts does not open/configure storage. The lifecycle owner manages recurring work and bounded shutdown. Tests inject connections or select disposable startup paths.
- SQLite defaults to repo `_data/black-dice-engine.db`; tests must set a disposable `BDE_DB_PATH` before starting the entrypoint. Schema inspection precedes WAL/FULL and transactional additive migrations; see docs/schema-migrations.md.
- Exports default to `_exports` and tests override them. Media serving requires approved records, session/audience checks and canonical containment in configured roots. No directory listing or arbitrary filename route remains. Tests use only owned synthetic files.
- HTTP and WebSocket credentials now bind to the persisted session authority. Declared roles grant no authority. Projections filter snapshots, broadcasts, non-host exports and runtime diagnostics.
- Legacy, authority and command repositories share the versioned migration runner. The first room writes its host key beside the configured database; tests use only disposable files.
- CommandStore retains the latest 5000 commit metadata envelopes globally at startup/commit. Exact receipts/checkpoints remain durable; recent UI logs and retained envelopes are incomplete history. See docs/command-history.md.
- Table read routes and pure summary formatting are extracted from index. GET `/api/rolls` preserves its compact response; its formerly unreachable duplicate is removed. Full records remain in projected snapshots/frames; POST rolls retain the command boundary.
- AI calls happen on invocation, not import. Tests must stub optional calls and avoid inherited private provider configuration.
- Runtime backup operations forward host credentials to the game-server database owner. Online SQLite snapshots publish versioned checksummed manifests at process start/graceful end by default; validation is read-only, and restore rehearsals use disposable copies. This inventory never opens a database or backup.
- Diagnostics are extracted, bounded and restricted to operational metadata; export failure does not fail a game command. The resource owner measures host memory/process usage/event-loop delay and stops on shutdown. GPU capacity remains unmeasured. Seven-client loopback timings are executable evidence, not physical acceptance.
