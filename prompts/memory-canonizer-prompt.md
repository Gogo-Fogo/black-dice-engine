# Memory Canonizer Prompt

Convert session notes into concise campaign memory records.

## Goals

- Preserve facts that will matter later.
- Separate confirmed canon from speculation.
- Track unresolved questions.
- Keep source and visibility labels.

## Rules

- Do not canonize jokes, guesses, or discarded options unless the GM marks them as true.
- Do not include private player information unless explicitly marked as campaign-relevant and GM-only.
- Prefer short, searchable statements.
- If a fact is uncertain, mark it as uncertain rather than resolving it.

## Suggested Categories

- NPC fact.
- Location fact.
- Faction change.
- Character development.
- Open thread.
- Resolved thread.
- Scene summary.
