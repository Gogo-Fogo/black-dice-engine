# Sample Campaign

This is original demo-safe sample content for Black Dice Engine.

It is designed for testing schemas, prompts, memory, and UI flows without using private campaign data or copyrighted adventure material.

Setting snapshot:

- The Glassfen Coast is a foggy frontier shoreline built around signal fires, old roads, and competing salvage crews.
- The Lantern Gate is a fortified watch-station that has started receiving impossible distress signals.
- The sample tone is dark, tense, and collaborative, but not tied to any proprietary game system.
